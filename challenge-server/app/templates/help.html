How to submit

Submitting your model

You upload your code and weights as a zip; the server runs them in one of the environments below, on its GPU and without internet access. The full guide is in the course documentation.

1. Make the zip

From the final-assignment folder of your repository:

python -m submission.package --track consistency --checkpoint checkpoints/my-run/best.pt --base-image pytorch

This creates submission_consistency.zip with:

submission.yaml     which base image, which checkpoint
model.pt            your weights
consistency/        your track folder: predictor.py, model.py, ...
wheels/             optional: extra packages as .whl files

2. Choose an environment

{% for key, b in cfg.base_images.items() %} {% endfor %}
base_imageContentsDocker image (to test locally and on Snellius)
{{ key }}{{ b.description }}{{ b.image }}

Need a package that is not in the image? Put its wheel files in wheels/ (pip download --only-binary=:all: -d wheels <package>); they are installed offline before your code runs.

3. Upload it

Open the page of your track, choose your name, enter your password and upload the zip. You can follow the queue; your results and log appear on the submission page and under My submissions.

{% if cfg.submissions.allow_custom_images %}

Advanced: a complete Docker image

If the environments above are not enough, upload a complete image (docker save -o image.tar <name>). It must contain Python with PyTorch, NumPy and Pillow, your track folder in /app and your weights in /app/model.pt. The server runs its own copy of the harness in it. Images are large: use this only if you need it.
