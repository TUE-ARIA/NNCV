## The notebooks

The notebooks are optional exercises in PyTorch. They are not graded, but they are the best preparation for the final assignment.

Run them in **Google Colab**: the button on a topic page opens the notebook with a free GPU, so you don't install anything.

1. Click **Open in Colab** on the topic page.
2. Choose **File → Save a copy in Drive**, so your changes are kept.
3. Check that a GPU is selected: **Runtime → Change runtime type → T4 GPU**.

You can also download a notebook and run it locally, in an environment with PyTorch and torchvision.
